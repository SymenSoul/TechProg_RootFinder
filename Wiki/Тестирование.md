# Тестирование

## Unit-тесты

Тесты написаны на Qt Test (QTest).

| Проект            | Что проверяется | Проверок |
|-------------------|-----------------|----------|
| `MathServerTests` | `MathSolver`: значения уравнений и производных, оба метода на всех уравнениях, точность, граничные случаи. `Database`: регистрация, вход, повторный логин, запись истории. `CommandParsing`: команды `reg`, `auth`, `solve`, неверные команды | 51 |
| `MathClientTests` | `ClientController`: формирование команд и разбор ответов сервера, одиночка | 19 |

Запуск:

```bash
cd MathServerTests && qmake && make && ./MathServerTests
cd MathClientTests && qmake && make && ./MathClientTests
```

Результат текущей версии: `51 passed, 0 failed` и `19 passed, 0 failed`.

### Что значит XFAIL

Шесть тестов сервера проверяют требования спецификации, которые сейчас нарушены. Они помечены
макросом `QEXPECT_FAIL` и в выводе выглядят так:

```
XFAIL  : ServerTests::testSolveRequiresAuth() Дефект №2: solve выполняется без авторизации
```

Такие тесты не считаются упавшими. Когда дефект исправят, тест станет `XPASS` и упадёт —
это напоминание убрать `QEXPECT_FAIL`. Подробнее — в `TESTING.md`.

Тесты запускаются и при сборке Docker-образа (см. [[Установка и запуск]]).
